# Infinite Sky Explorer - User Guide

Welcome to the Infinite Sky Explorer! This tool allows you to easily browse, search, and manage your files through a beautiful, web-based interface.

## Browsing Files
- **Navigation**: Click on any folder icon (📁) in the list to open that folder.
- **Breadcrumbs**: At the top of the page, you'll see a breadcrumb trail (e.g., `Home / projects / InfiniteSky`). Click any part of the path to instantly jump back to that folder.
- **Hidden Files**: By default, the system hides hidden/system files to keep the interface clean. You can view them by unchecking the **"Hide hidden files"** toggle at the top right.

## Searching
- Type anything into the **"Search files and folders..."** bar at the top right.
- The view will instantly update to show all files and folders that match your query across all subdirectories.
- The results show the full path of the item so you know exactly where it is located. Clear the search bar to return to your previous folder.

## File Operations
You'll notice action buttons next to the files in the list:

- ⬇️ **Download**: Click the download button next to any file to securely download it to your local machine.
- ✏️ **Move/Rename**: Click the pencil icon to rename a file or move it to a completely different folder. A window will appear asking for the new path.
- 🗑️ **Delete**: Click the trashcan icon to permanently delete an item. **Warning:** If you delete a folder, all files inside it will be permanently deleted as well!

## Uploading Files
- Navigate to the folder where you want your new file to go.
- Click the blue **"Upload File"** button at the top right.
- Select your file and click Upload. The file will be placed in the folder you are currently viewing.

## Advanced: Path Traversal
By default, you are locked into the "Home" directory designated by the system administrator. If you need to access files outside this directory (e.g., your entire hard drive), and if you have the permission to do so, uncheck the **"Prevent Path Traversal"** toggle at the top right.
